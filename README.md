# Cecilia Restaurante

**Cecilia ocupa la portada del repositorio y de GitHub Pages.** La página principal está publicada en [camilocc7-hub.github.io/Blessed](https://camilocc7-hub.github.io/Blessed/).

## Proyectos

- [Cecilia Restaurante · Avance 1](https://camilocc7-hub.github.io/Blessed/avance-1/) — primera entrega de estructura semántica y diseño adaptable.
- [Cecilia Restaurante · Avance 2](https://camilocc7-hub.github.io/Blessed/avance-2/) — lógica de interfaz, Fetch, persistencia local y validaciones.
- [English Career](https://camilocc7-hub.github.io/Blessed/english-carrer/) — simulador de carrera en inglés.

## Organización

La carpeta `avance-1/` conserva la versión del primer avance. `avance-2/` contiene los archivos HTML, CSS, JavaScript y datos de la segunda entrega. `english-carrer/` mantiene el proyecto de inglés por separado.

La raíz del repositorio conserva una copia publicable de Cecilia para que el enlace principal abra directamente el restaurante. Las dos versiones de Cecilia comparten el logotipo ubicado en `assets/cecilia-logo.webp`.
