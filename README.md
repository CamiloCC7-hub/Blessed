# English Carrer

Simulador interactivo de carrera en la Premier League. El jugador comienza a los 16 años, elige club y toma decisiones que afectan sus temporadas.

## Jugar

La portada de este sitio es English Carrer. También se puede abrir el archivo index.html desde un navegador.

## Tecnologías y restricciones

- HTML, CSS y JavaScript Vanilla.
- Construcción de la interfaz con el DOM.
- Sin canvas, librerías externas, almacenamiento local ni llamadas de red.
- El estado de la carrera vive en variables y estructuras JavaScript durante la partida.

## Conceptos del taller

- Variables y tipos primitivos: edad, GRL, etapa de la carrera y estadísticas.
- Condicionales: rendimiento, decisiones, ofertas y premios.
- Arreglos: clubes, posiciones, eventos, elecciones, historial y premios.
- Objetos literales: jugador, clubes, eventos, estadísticas y recompensas.
- Funciones declaradas para iniciar, simular, resolver decisiones y renderizar.
- Eventos del navegador para botones, campos y errores de imágenes.
- Manipulación del DOM con creación de elementos, texto y nodos.

## Evento especial de temporada

Un evento obligatorio de ausencia puede narrarse como lesión, conflicto con la directiva o decisión del entrenador. Esa temporada queda sin partidos ni estadísticas y se omite el año siguiente; el fondo rojo identifica la ronda afectada.

## Estadísticas por posición

Los delanteros priorizan goles; los mediocampistas, asistencias y pases clave; y defensas y porteros, vallas invictas. El historial siempre muestra goles y asistencias, también cuando el valor es cero.
