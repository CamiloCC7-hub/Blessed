# Cecilia Restaurante · Avance 2

Versión organizada de la segunda entrega, separada de la portada y del primer avance.

## Abrir

- [Sitio del Avance 2](https://camilocc7-hub.github.io/Blessed/avance-2/)

## Módulos

- `index.html`: estructura de la página y componentes de interfaz.
- `styles.css`: diseño responsive.
- `interactions.js`: eventos, validación dinámica, Fetch, estado de carga y formularios.
- `data.json`: datos estructurados de curiosidades para la petición local.

Los borradores y las solicitudes de demostración se guardan en el navegador con `localStorage`. Las reservas y encuestas no se envían automáticamente a un servidor; WhatsApp Web permite revisar y enviar el mensaje desde la cuenta del visitante.
